      How this diagram is built

      It is generated from the TypeScript types in and redraws whenever they change.

      An entity is an exported type with an id field, or one tagged /** @entity */. Types without an id that sit inside a record are drawn as embedded types.

      A field named after an entity (listingId, listingIds) links to it. Anything else takes a tag: /** @ref User */, /** @external PayPal */ for an id that lives outside the mock, or /** @ref none */ for an id with no single target.
